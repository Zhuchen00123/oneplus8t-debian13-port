# USB附近局部烫手报告（2026-10-04；原因未确定）

用户报告长时间电量仍为100%，随后明确位置为“屏幕下部靠近usb处”，程度为“烫手”。该实际报告使长期插电安全性处于未验收状态，不能用电池温度或停充寄存器正常忽略局部过热。

后续用户确认拔线约5分钟后自行重新插线、手机开机，之后在短按熄屏服务部署后回复“已不烫手，短按能亮屏和熄屏”。这是当前症状缓解及按键功能通过的证据；拔线冷却、屏幕状态和时间同时变化，没有孤立对照，不能归因为屏幕或宣称充电电路全部正常。见[电源键切屏记录](powerkey-screen-20261004.md)。

最近只读复核：REG08=0x06、CHG_EN关闭、owned=1、续约有效、无恢复错误；健康状态为100%、Not charging、电池37.9°C、CPU最高42.6°C。此前一轮直接电量计读取current_now为0；这不是USB输入电流或接口附近温度。实际USB输入功率、局部温度和发热点的器件尚未测得，不能据此确认发热原因或完整物理停充效果。

已明确要求用户立即拔下USB停止外部供电，先冷却并暂停服务器使用；等待确认是否已拔线、开始降温以及有无异味/鼓包/变色。没有远程强制关机、改PD电压电流、写其它充电位或在烫手状态下继续负载/插电测试。手机是否已断开、策略服务是否仍运行尚须实际核验，不能写成已停用服务。

以上是初始等待阶段。后续一次SSH因USB管理源地址消失而失败，没有要求为检查重新插线；用户自行恢复连接后，仅读取显示/温度并按其明确要求安装屏幕按键服务降低发光负荷，没有继续充电/负载实验。重新插线后电量计曾显示Charging，稍后直接读取Not charging/current_now=0，停充位持续关闭；该状态延迟保留，不能单凭读回代替完整物理充电周期。

[MPS官方MP2762A数据手册](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP2762AGV/document_id/9073/)区分充电使能与DC/DC/电源路径。外部电源继续供应系统可以解释电池电量不下降，是硬件机制提供的一种可能；不等于本机已完成旁路供电验证，也不能解释或合理化局部烫手。还需排查输入供电、线缆/接触、充电转换电路及未覆盖的管理/热保护路径。

首次只读检查因自动审批超时未执行；一次重试成功，只读取现有接口。未发生由安全理由拒绝的硬件写入尝试。

下一步先确认安全断开与冷却，之后再准备有界、可恢复的诊断方案。不能为快速降至80%擅自切断DC/DC、改变BATTFET或其它未知寄存器；不能在未核对退电路径时用强制关机代替拔线。异常持续或有异味、鼓包、变色时保持停用并进行硬件检查。
