## 计量口径

CNB 当前官方定价按云原生开发 CPU **核时**计量，即节点核数×运行时长，多个运行环境的用量累积；不是按SSH或HTTP隧道条数另收一份实例费用。同一实例增加转发进程／端口不会因此变成另一个节点。

目前官方页面给出每个顶级组织云原生开发1600核时／月，超额标准0.125元／核时；可用额度不足且未提升用量上限时可能被停止，具体结算取决于组织预算绑定与已用额度。本轮没有读取组织账单、已用／剩余核时或预算，不声称已经产生扣费或保证免费。

来源：[CNB官方定价](https://docs.cnb.cool/zh/saas/pricing.html)，2026-10-09读取。账单级金额需在组织设置的用量管理核验；当前实例数、静态规格和长期开机时长不能替代实际账单。
