# r2 内建显示与触摸

2026-10-04，本机 KB2000 使用完整匹配的 `7.2.0-kebab-debian13-r2+`。显示修复及运行布局触摸解析都已编入内核，旧触摸接管服务已禁用。

## 构建

```bash
bash scripts/linux/prepare-kernel.sh /home/<user>/oneplus8t-build-r2 r2
bash scripts/linux/build-kernel.sh /home/<user>/oneplus8t-build-r2 dtb
bash scripts/linux/build-kernel.sh /home/<user>/oneplus8t-build-r2 kernel
```

选择全新 Linux 文件系统目录。上游和补丁在 sources.lock.json 固定，按 0001 → 0003 → 0004 → 0002-r2 应用，配置只修改 r1 的 LOCALVERSION。默认 profile 仍为 r1。

`install-kernel-group.py --rootfs <离线构建目录/rootfs> --kernel-artifacts <同次构建组>` 校验输入 hash、模块归档路径、版本与数量，安装 Image/配置/DTB/模块并 depmod。它只操作主机 rootfs，不连接手机。使用自己的已校验根文件树、固件、包来源、SSH 身份和 boot 参数，经持久/RAM 打包工具生成完整组，再比较 initramfs/rootfs 模块的实际字节。

原位 boot/modules 更新可显式传 `build-server-candidate.py --rootfs-uuid <自己的已核对 UUID>`；新安装默认生成 UUID。必须先备份原 boot 和根文件树，保留旧模块与恢复路径。运行中的逻辑文件备份不是原子或原始分区备份。本仓库不包含通用刷机脚本或可用镜像。

## 限制
