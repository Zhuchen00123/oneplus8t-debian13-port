## 发热与使用边界

用户曾报告屏幕下部靠近USB处烫手。后续拔线约5分钟并自行重插，部署切屏后确认“已不烫手，短按能亮屏和熄屏”；本轮电池传感器采样34.3°C。**电池传感器不是接口局部温度，症状缓解不能证明根因消除或长期插电安全。**

限充只控制已验证的CHG_EN路径，没有切断USB系统供电，也未验证旁路供电。显示亮度0减少发光，不代表整条显示电源链关闭。局部烫手再现时应拔线停用、冷却并排查，不盲改PD、BATTFET或其它寄存器。
